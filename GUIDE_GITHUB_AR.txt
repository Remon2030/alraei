الراعي PWA v2.1 — نسخة GitHub Pages (بديل للدومين المتقطع)

قبل النشر: اختبر أن المواقع التي تنتهي بـ github.io تعمل على شبكة 4G لديك. إذا كانت غير متاحة، فلن يحل النشر عليها المشكلة.

1) افتح github.com على Chrome في أندرويد وسجل دخولًا.
2) أنشئ مستودعًا جديدًا باسم alraei، واجعله Public (الملفات البرمجية فقط عامة، البيانات لا تُرفع).
3) فك ZIP في مجلد على الموبايل، وافتح المستودع ثم Add file → Upload files. اختر جميع الملفات الموجودة مباشرة في المجلد (index.html, sw.js, status.html, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png). ارفعها في جذر المستودع ثم Commit changes. لا ترفع ZIP كملف واحد.
4) من Settings → Pages اختر Deploy from a branch → main → / (root) → Save.
5) رابط التطبيق يكون https://YOUR_USERNAME.github.io/alraei/ بعد النشر.
6) افتح الرابط و /status.html وتأكد من «جاهز للتشغيل دون إنترنت»، ثم اختبر إعادة فتح التطبيق بوضع الطيران.
7) على iPhone افتح نفس الرابط في Safari، Add to Home Screen، وشغله من الأيقونة مرة أثناء وجود الإنترنت ثم جرّب أوفلاين.

مهم: لو كنت سجلت أشخاصًا على رابط Cloudflare أو ملف HTML قديم، لازم تصدّر نسخة احتياطية مشفرة قبل الانتقال؛ تغيير الدومين يعني مساحة تخزين جديدة.
